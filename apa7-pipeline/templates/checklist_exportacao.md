# Checklist mínimo antes da exportação

- [ ] Capa completa com afiliações e contato
- [ ] Resumo (150–250 palavras) e palavras-chave (3–6)
- [ ] Seções: Introdução, Método, Resultados, Discussão, Conclusão
- [ ] Agradecimentos / Financiamento / Conflito de interesse
- [ ] Todas as citações no texto têm entradas na lista de referências
- [ ] Todas as entradas da lista são citadas no texto (ou discrepâncias justificadas)
- [ ] Referências com DOI válidos quando disponíveis
- [ ] Similaridade abaixo do limite definido (padrão 15%)
- [ ] Declaração de ética (obrigatória se houver participantes humanos/animais)
- [ ] Exportação DOCX/PDF + BibTeX/RIS
- [ ] Relatório JSON de verificação gerado
- [ ] Registro de revisão (histórico de versões) atualizado
